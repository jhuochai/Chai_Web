# 艙門轉場

採用使用者定稿的關門圖比例。門框與門板共用 `transit-door-closed.webp`，以互補裁切分層；僅門板繞左側鉸鏈旋轉至 70 度，鏡頭及固定門框不做縮放或換圖。背後為 `transit-corridor.webp` 過道底圖。

## 載入順序

1. 收到有效站點導航請求，顯示關門並暫停底層互動及捲動。
2. 180ms 後切換站點，等待 React 呈現、圖片載入/解碼及可見背景圖片。
3. 準備完成後開門 1000ms，再淡出 260ms，恢復互動並聚焦目標頁標題。
4. 減少動態效果模式仍等待資源，但以 180ms 淡出取代旋轉。

圖片失敗、等待超過 8 秒時放行，避免訪客卡在轉場；元件卸載時取消等待並釋放捲動鎖。首頁原有入場動畫不在此次替換範圍。

## 資產

- 關門：使用者附件 `codex-clipboard-e5258dc6-2431-4f90-bc94-a412b7937aa6.png`，轉存 WebP。
- 過道：內建 ImageGen 編輯已選開門參考圖，提示為移除前景門板、保留門框與鏡頭、補齊空曠飛船過道；轉存 WebP。
- 兩張合計約 460 KB；正式網站不依赖本機暫存路徑。

## 驗證

開發伺服器上的 `/design-previews/door-transition-review.html` 可固定查看關門、半開、開門狀態，直接載入正式轉場 CSS。桌面比對固定門框的 bounding rect、transform、clip-path 完全一致；390×844 檢查門框完整可見。

`npm test -- --maxWorkers=2` 檢查本站 `src`；已將舊工作樹中的副本排除，避免副本測試讀取主專案樣式造成混淆。

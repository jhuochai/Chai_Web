# 航跡樹工作閱讀台與遊戲花觀測台設計規格

日期：2026-08-27  
範圍：航跡樹站中，點擊工作絲帶或遊戲花後展開的介紹畫面，以及絲帶／花朵的識別配色

## 目標

將目前偏向 CSS 簡筆框架的工作與遊戲介紹畫面，改為真正存在於航跡樹場景裡的工業機械設備。訪客打開內容時仍能看見樹與所在環境，不會像跳進另一個網站或一般彈出視窗。

同時讓每段工作與每款遊戲具有可辨識的專屬配色，但仍共享同一種材質、造型與光影語言，避免花朵與絲帶像來自不同素材包。

## 核心視覺方向

- 世界觀：Arcane 氛圍的舊工業科幻站點，帶手繪 2D 筆觸與可信的 3D 光影。
- 材質：黑化鋼鐵、磨損黃銅、細微鏽蝕、布料纖維與局部能源微光。
- 禁止使用：透明玻璃卡、細線 HUD、純 CSS 空框、漂浮圓角卡片、過度乾淨的現代控制台。
- 文字不烘焙進圖片；標題、日期、說明、成果與媒體均使用 HTML 疊加，以保留中英文、響應式與無障礙能力。

## 共用裝置架構

工作與遊戲畫面共用一座位於畫面中央下方的機械底座，讓兩種內容明確屬於同一站點。

- 整座裝置水平置中，中心軸對準畫面與樹幹中心。
- 桌面／台座寬度約為可視畫面的 62–68%。
- 裝置占畫面下半部約 35–40%，樹與環境至少保留 60% 可見面積。
- 桌面具輕微透視傾角與真實厚度，不是正面平板，也不貼齊任一側。
- 開啟時由下方升起並帶金屬鎖定感；關閉時降回畫面下緣。
- 背景樹只稍微降亮與降低對比，不做大片純黑遮罩。
- 桌面中央保留主要內容區；按鈕、鉸鏈、固定座與照明沿機械結構排列，不使用獨立漂浮卡片。

### 工作模式：航跡閱讀台

- 共用底座上裝入絲帶固定夾、檔案承托板與小型機械閱讀燈。
- 被點擊的絲帶從原本樹枝延伸至閱讀台，視覺上保持同一條布帶，不再分層或脫軌。
- 工作標題、期間、職稱、摘要與列點位於中央閱讀面板。
- 絲帶的專屬色只影響布面、固定夾反光與局部照明；主機械仍維持黑鐵與霧金。

### 遊戲模式：花朵觀測台

- 共用底座換成植物固定座、環形觀測鏡、低亮度掃描燈與媒體插槽。
- 花朵位於設備內部偏左，但整座觀測台仍水平置中；右側安排遊戲名稱、文字與截圖／影片區。
- 花朵本體不使用短金屬枝扣；只保留統一花型、花瓣、花心與自然短梗或無梗狀態。
- 花朵與右側吊燈維持合理比例；樹上未靠近時較小，隨鏡頭推近同步放大，點開後才在觀測座呈現可閱讀尺寸。

## 花朵統一規則

- 所有遊戲使用同一套花朵輪廓與花瓣數量，差異來自花瓣配色、花心結構、紋路與微光。
- 花瓣材質為帶手繪筆觸的半透礦物／植物混合質感，不做塑膠、霓虹貼圖或遊戲 Logo 直接貼花。
- 每朵花最多使用兩個主色、一個輔色與一個受控光色。
- 發光集中在花心和細小葉脈，花瓣邊緣只保留弱反光。
- 樹上花朵的亮度低於場景吊燈，避免搶走整棵樹的視覺重心。

## 工作絲帶統一規則

- 四條絲帶共用相同寬度、布料織紋、長度邏輯、泛金收邊與懸掛結構。
- 絲帶邊緣的金色為受光形成的舊金屬絲線，不是整條高亮黃色描邊。
- 不同工作只改變布面主色、細紋與少量反射色。
- 遠景時配色仍可辨識但不鮮豔；鏡頭靠近後才顯露布料與金屬絲細節。

## 互動流程

1. 絲帶與花朵從場景一開始就位於樹上，尺寸跟隨鏡頭縮放。
2. 未達互動距離時仍可看見，但不呈現誇張光圈或文字標籤。
3. 鏡頭靠近後，以細微發光、布料飄動或花瓣呼吸提示可點擊。
4. 點擊後共用機械底座由下方升起，對應的絲帶或花朵連接到設備。
5. 內容出現後仍能看見背景樹；媒體可播放，文字可捲動。
6. 關閉時裝置降下，鏡頭進度與日夜狀態保持不變，不要求使用者重新向前滾動。
7. `Escape`、明確的關閉控制與點擊非設備區域均可關閉；關閉後焦點回到原本的絲帶或花朵。

## 動態與無障礙

- 裝置升降採平順的機械緩出，不使用彈跳。
- 絲帶只做低幅度布料飄動；花朵只做低頻呼吸光，不能持續閃爍。
- Ready or Not 的藍光不得高頻閃動，避免造成不適。
- `prefers-reduced-motion` 下改為短淡入淡出，取消升降、呼吸與飄動。
- HTML 文字需符合最低 4.5:1 對比；互動控制具鍵盤焦點與可讀名稱。
- 行動裝置上，設備仍保持居中；文字與媒體改為設備內的直向捲動，不將機械框拆成多張卡片。

## 製圖交付

正式製圖分為可重用層，不把所有狀態烘焙成一張完整截圖：

1. 共用中央機械底座。
2. 工作模式的絲帶閱讀附件。
3. 遊戲模式的花朵觀測附件。
4. 四條獨立透明背景絲帶。
5. 十二朵獨立透明背景花朵。
6. 必要的遮罩、陰影與前景光效。

每張圖在正式接入前須先提供預覽，檢查構圖、比例、色彩與透明邊緣；核准後才複製到網站資產資料夾。

## 驗收條件

1. 閱讀台與觀測台均以畫面中心線為基準，不再明顯偏左或偏右。
2. 開啟介紹內容後，背景樹至少保留約 60% 可見面積。
3. 十二朵花共用同一花型與材質語言，但能僅靠配色辨識不同遊戲。
4. 四條絲帶共用相同結構與舊金收邊，且色彩與工作性質相符。
5. 絲帶與花朵的遠近縮放符合樹與鏡頭比例，不會在遠景時比吊燈更大。
6. 裝置、文字、圖片與影片在桌面與行動裝置均不溢出。
7. 關閉介紹畫面後保持原本鏡頭進度與日夜狀態。
8. 所有開啟、關閉、鍵盤操作、減少動態模式與中英文內容測試通過。

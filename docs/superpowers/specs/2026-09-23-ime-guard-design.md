# 中文輸入提醒工具：第一版設計草案

狀態：待使用者確認。獨立 Windows 桌面小工具，程式預計放在 `ime-guard/`。

## 使用者需求

- 偵測「想打中文，卻在英文模式打出注音對應英數字」。
- 首次使用選擇常用輸入法，設定頁可以更改。
- 第一版支援微軟注音的標準注音鍵盤；其他輸入法標示尚未支援，不套用錯誤規則。
- 疑似打錯時提醒；使用者希望可使用晃動或其他可見提示。

## 方案選擇

1. 建議：本機注音音節規則。以有效音節、聲調和連續音節判斷，可離線執行，容易測試；可能漏判，也可能把部分英數字組合誤判。
2. 字詞字典加權：可補足部分聲調較少的句子，但需要字典來源、授權及持續調整。留待後續改善。
3. 語言模型判斷：可使用更多上下文，但增加延遲、部署及資料處理成本；不納入第一版。

## 使用流程與提醒

首次啟動顯示輸入法選擇和提醒示範。確認後常駐通知區；提供設定、暫停／繼續及退出。

預設浮動提示：「是不是忘了切換中文？」持續約 1.5 秒，不搶走輸入焦點，不攔截按鍵。設定可開啟提示框輕微晃動及音效，預設音效關閉。第一版晃動的是提示框，不搬動其他應用程式視窗或整個桌面。每次提醒後冷卻 5 秒。

## 偵測規則

- 僅在支援的輸入設定且能確認目前輸入模式為英文時判斷。無法讀取狀態時暫停該視窗的判斷，設定頁顯示原因。
- 僅在記憶體保留短期按鍵序列：最多 32 個按鍵、閒置 3 秒清空。
- 第一版採保守門檻：至少兩個相連有效注音音節，每個具有明確的二、三、四或輕聲聲調鍵。至少四個按鍵，且必須完整匹配音節規則。
- 範例：英文模式輸入 `su3cl3`，對應「ㄋㄧˇ ㄏㄠˇ」（你好），應提醒。只有 `su`、一般英文單字或純數字，不提醒。
- 包含一聲／空白分隔、沒有足夠明確聲調訊號的序列，第一版可能漏判；不以任意英數混合就觸發。
- 切換視窗、輸入模式、移動游標、滑鼠點擊、刪除、貼上快捷鍵或 Ctrl／Alt／Win 快捷鍵時清空序列。忽略程式注入按鍵。
- 提供暫停及應用程式排除設定，方便排除程式編輯器等容易出現英數混合的情境。

## 實作結構

採 C#／Windows Forms 桌面程式，優先使用本機已有的 .NET Framework 編譯器，不新增網站依賴。

- 輸入設定：定義鍵盤對應及合法注音音節，日後新增輸入法時擴充。
- Windows 狀態與按鍵來源：取得目前前景視窗、輸入模式及按鍵；hook 回呼只轉交事件並立即返回，避免阻塞正常打字。狀態查詢在回呼外執行，設置逾時，並檢查前景視窗一致性。
- 偵測器：純規則模組，接收序列與狀態，輸出是否提醒，不依賴 UI。
- 提醒與設定：負責不取焦點提示、冷卻、通知區及使用者設定。

模式查詢必須以微軟注音及實際應用程式驗證，不能把取得鍵盤語言等同取得中／英文模式。讀取失敗不猜測成英文。

## 資料與錯誤處理

不連網、不儲存按鍵或輸入內容。磁碟只保存輸入法選擇、提醒選項及排除清單。辨識到密碼欄位時立即清空並停用偵測；跨應用程式的密碼欄位辨識有相容性限制，必須如實說明，不宣稱所有欄位都能辨識。

無法安裝 hook 時顯示明確失敗狀態，不顯示為正常執行。退出時解除 hook、清除暫存並移除通知區圖示。不自動修改或替換使用者打出的文字。

## 驗收

- 規則測試：`su3cl3` 應提醒；一般英文、純數字、單一未完成音節、不合法音節及短序列不提醒。
- 狀態測試：中文／未知模式、暫停、排除程式、切換視窗、逾時清空及冷卻期間不提醒。
- 實際互動驗證：微軟注音搭配記事本與瀏覽器輸入框；確認提醒不奪取焦點、不吞鍵、設定可保存。
- 未能完成的實際應用程式／密碼欄位驗證必須列為限制，不以規則測試通過宣稱全面相容。

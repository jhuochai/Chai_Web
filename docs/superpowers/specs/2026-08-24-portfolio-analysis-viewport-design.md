# 作品分析艙觀景窗與案例卡牌設計

## 目標

把目前偏扁平、操作方式不直覺的 Circular Gallery，改成與 Hero 駕駛艙同一世界觀的「作品分析艙」。訪客看見的主體是一座厚重圓形金屬艙門，以及可直接點擊的案例資料匣。

## 視覺結構

- 圓形外框改為完整的工業科技艙門素材，而不是只靠多層 CSS 圓圈疊出。
- 材質沿用 Hero Page：深色鋼鐵、香檳金收邊、鉚釘、刻度與少量藍色儀表光。
- 艙門內側保持深色，讓金白卡牌與 Logo 成為視覺焦點。
- 中央卡牌正面朝向訪客；相鄰卡牌向後退並稍微傾斜，保留 Circular Gallery 的環形空間感。

## 案例卡牌

### 貓咪造咖

- 象牙白金屬或陶瓷複合面板。
- 香檳金框、細小鉚釘、很淡的電路刻線與少量使用痕跡。
- 中央保留使用者提供的彩色「貓咪造咖」Logo。
- 使用淡藍指示光，維持科技感但不改變 Logo 原本色彩。

### 暗棋

- 深胡桃木面板，搭配黑金金屬結構。
- 中央保留使用者提供的「將」棋子 Logo。
- 使用琥珀金指示光，讓木質棋子仍能融入飛船分析艙。

兩張卡牌都只在底部保留小型金屬銘牌顯示案例名稱，不放長文，也不把案例截圖當作封面。

## 互動

- 刪除目前下方兩個獨立案例選擇框。
- 整張卡牌本身是可點擊按鈕；點擊後直接開啟對應案例分析桌。
- 中央卡牌具有較亮的金屬邊光；非中央卡牌降低亮度並向後傾斜。
- 拖曳、滑動或鍵盤左右鍵可切換中央卡牌。
- 點擊時卡牌短暫前移，像資料匣被送入分析機，再開啟案例內容。
- 卡牌保留清楚的鍵盤焦點與可讀取的按鈕名稱。
- `prefers-reduced-motion` 下取消前移與傾斜動畫，以淡入淡出替代。

## 實作邊界

- 第一階段先產出作品分析艙視覺稿，確認圓框、卡牌比例與材質。
- 視覺稿核准後，再建立圓形艙門圖片與兩張卡牌素材並接入現有 Portfolio。
- 保留現有案例分析桌、案例資料與同頁開啟行為。
- 不在這次調整案例內頁內容、成效文案或其他站點。

## 驗收條件

- 首屏不再顯示案例截圖封面與底部兩個選擇框。
- 貓咪造咖為金白科技卡牌；暗棋為深胡桃木黑金卡牌。
- 兩張卡牌中央皆使用指定 Logo。
- 點擊任何可見卡牌都能開啟正確案例。
- 圓形艙門在桌面與手機尺寸都不裁掉主要卡牌，也不出現文字溢位。
- 視覺上能明確辨識為 Hero 駕駛艙延伸出的作品分析艙。
